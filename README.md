National Parks Road Trip Planner

This project builds a seven-day Texas park itinerary using live data from the National Park Service and the National Weather Service. It filters parks by activity, pulls real-time forecasts, scores each location for the best weather, and assigns parks to specific days with two flex days at the end for travel or rest. The results are saved automatically in JSON and CSV formats.

The program is written in Python 3.13 and runs in a virtual environment. A simple .env file is used for the API key and configuration values.

The core logic is complete and functional. The optional Google Sheets upload feature is planned next and will be added over the weekend.
